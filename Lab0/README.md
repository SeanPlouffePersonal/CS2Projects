# Lab 0 Student Starter

This IntelliJ-compatible starter project contains the files for Lab 0.

1. Open this folder in IntelliJ IDEA.
2. Configure a Java 17 (or newer) JDK if prompted.
3. Allow IntelliJ to load the included Maven project and download JUnit.
4. Complete each `TODO` in `src/main/java/CourseGrade.java` and `src/test/java/CourseGradeTest.java`.
5. Update the name in `src/main/java/LabZero.java`.
6. Run `LabZero`, then run both JUnit 5 tests.
7. Submit the complete project or the required Java files as directed.

You may use another Java IDE, but course demonstrations will use IntelliJ IDEA.
